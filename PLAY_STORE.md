# Материалы для публикации в Google Play Console

Всё, что нужно скопировать в Play Console, и пути к файлам графики.
Версия: 1.1.3, `versionCode` 6. Пакет: `com.personalsky.app`.

## 1. Артефакт для загрузки

```
app\build\outputs\bundle\release\app-release.aab
```

## 2. Название и описания

**Название приложения (до 30 символов)**

```
Личный небосвод
```

**Краткое описание (до 80 символов)**

```
Трекер привычек, где каждый день становится звездой в личном созвездии
```

**Полное описание (до 4000 символов)**

```
«Личный небосвод» — спокойный трекер небольших целей. Каждый отмеченный день
зажигает звезду, а завершённый путь остаётся в личной карте неба.

Привычки часто исчезают не из-за отсутствия мотивации, а из-за чувства вины.
Обычные трекеры сводят прогресс к галочкам и сериям, где один пропуск обнуляет
всё. Здесь вместо этого — визуальная история пути.

КАК ЭТО РАБОТАЕТ
• Создайте небольшую цель на 5, 7 или 14 дней.
• Приложение подберёт созвездие по длине пути: Кассиопея, Большая Медведица
  или Орион.
• Отмечайте выполнение в один тап: обычная звезда — минимальный шаг,
  яркая звезда — день, когда вы сделали больше.
• Пропущенный день не обнуляет путь: на его месте остаётся мягкая туманность.

ЧТО ЕСТЬ В ПРИЛОЖЕНИИ
• Карта созвездия с масштабированием и перемещением.
• История пути по дням и завершённые созвездия в архиве.
• Общий «Небосвод пути» — все звёзды и туманности на одной карте.
• Локальное напоминание в выбранное время.
• Виджет с текущим днём пути на главном экране Android.
• Экспорт завершённого созвездия в PNG для экрана блокировки.

ЛИЧНОЕ ПРОСТРАНСТВО БЕЗ ЛИШНЕГО
Приложение работает полностью на вашем устройстве. Нет обязательного аккаунта,
рекламы, внешней аналитики и серверной синхронизации: цели, отметки и настройки
остаются на устройстве. Отказ от разрешения на уведомления не мешает работе —
напоминание просто не появится.

«Личный небосвод» не обещает идеальную дисциплину. Он помогает увидеть движение
таким, каким оно было на самом деле: с маленькими огнями, паузами и продолжением.
```

## 7. Как были сняты скриншоты

Кадры сделаны на Pixel 8 (1080×2400) с debug-сборки, интерфейс которой совпадает
с релизом:

```powershell
python tools\make-store-database.py                     # база с целью «Утренняя зарядка»
python tools\take-store-screenshots.py -Out store-screenshots
python tools\check-store-assets.py personal_sky_play_icon_512.png `
    personal_sky_feature_graphic_1024x500.png (Get-ChildItem store-screenshots\*.png)
```

Скрипт съёмки сам скрывает системную панель, затирает значок заряда в верхней
полосе и проверяет, что кадры не повторяются.
